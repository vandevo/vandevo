# Van Vo

I build Worktugal, a community for people building a career or a business in Portugal. It started in Lisbon, where I host Lightning Talks at Kübe Coworking, and it is for the whole country. I also write the newsletter, which covers the rules nobody writes down about living and working here.

Most of my work is software and events. The Worktugal site is TypeScript and React on Supabase and Cloudflare, with Stripe and Resend for payments and email. For daily work I run Hermes Agent on DeepSeek and Claude Code on my own tools, and I report what breaks upstream, for example [hermes-agent#143052](https://github.com/NousResearch/hermes-agent/issues/143052).

The last Lightning Talks was on 5 November at Kübe: three speakers, ten minutes each, and a long Q&A. About 1,400 people follow the calendar at [luma.com/worktugal](https://luma.com/worktugal).
