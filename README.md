# Van Vo

I build Worktugal, a community in Lisbon for remote workers, freelancers and founders landing in Portugal. I host Lightning Talks at Kübe Coworking and write a newsletter about the rules nobody writes down.

## What I'm working on

- **Worktugal:** the community, the events and the newsletter. [worktugal.com](https://worktugal.com)
- **Lightning Talks:** ten minute stories from people living and working here. Last one was on 5 Nov at Kübe. [luma.com/worktugal](https://luma.com/worktugal)
- **Agents in daily work:** I run Hermes Agent on DeepSeek and Claude Code on my own tools, and report what breaks. One example: [hermes-agent#143052](https://github.com/NousResearch/hermes-agent/issues/143052).

## Tools I use

TypeScript, React, Supabase, Cloudflare, Stripe, Resend. Hermes Agent and Claude Code for the daily work.
